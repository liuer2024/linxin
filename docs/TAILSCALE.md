# 通过 Tailscale 跨网络连接

邻信现已支持读取本机 Tailscale 设备列表，连接不同地点电脑上的邻信。Tailscale 单独安装；邻信不内置 VPN、不自动登录、不修改访问规则，也不启用公网 Funnel。

## 使用

1. 两台电脑分别安装并登录 Tailscale，加入同一可互通的 tailnet。
2. 两边运行此版本或更新的邻信，使用默认监听设置。默认 TCP 端口为 47832。
3. 进入 **发现 → Tailscale**，点击重新探测，选择在线设备。
4. 如果对方使用不同邻信端口，先修改列表上方的端口（默认为 47832）。
5. 连接成功后进入同一套会话界面，可以聊天、查看已读和收发文件。
6. 首次连接显示身份未验证，通过可信渠道核对双方邻信指纹，再标记为已核对。

Tailscale 在线仅表示该设备在线，不保证邻信已启动。选择设备时，邻信才请求公开身份信息并建立应用连接，不会扫描整个 tailnet 的端口。

## 连接条件

- 系统防火墙以及 Tailscale grants/ACL 需允许双方访问对方邻信的 TCP 端口。消息、回执和文件拉取都可能需要反向连接。
- 邻信不能只监听 127.0.0.1。默认 `:47832` 监听包括 Tailscale 在内的本机网络接口；也可用 `-listen TailscaleIP:47832` 仅绑定对应地址。
- 不需要配置出口节点、子网路由器或 Tailscale Serve/Funnel。
- 使用普通系统网络模式的 Tailscale 客户端；本版没有接入 userspace SOCKS 代理。
- 局域网 UDP 发现不会穿过 Tailscale；跨网设备来自 Tailscale 的本地状态。
- 传输路径可能由 Tailscale 直连，也可能中继；本版不推测当前路径，界面只显示通过 Tailscale 连接。

## 客户端检测

优先查找 PATH 中的 `tailscale`，其次检查 Mac 的 `/Applications/Tailscale.app`、Homebrew 常见安装位置及 Windows 的标准安装目录。自定义路径可在启动时指定：

```sh
go run . -tailscale-cli /absolute/path/to/tailscale
```

邻信只执行 `tailscale status --json`。不需要配置 API Key。状态读取有 5 秒上限，输出有大小上限。未安装、未登录、暂停、等待管理员批准或状态读取失败时会显示相应提示。CLI JSON 结构可能随 Tailscale 更新变化，本版对额外字段保持兼容，但关键字段缺失时会报错。

## 设备身份

首次选择设备只读取公开身份信息，并检查响应中的指纹与实际 TLS 证书一致；这一步不会自动将设备标为可信。消息和文件始终使用固定指纹的 TLS 连接。

成功连接后，将 Tailscale 稳定设备 ID 与邻信证书指纹绑定，保存在用户数据目录 `tailscale-peers.json`。同一设备 IP 变化不会改变会话身份；同一 Tailscale 设备的邻信证书变化会拒绝自动连接。重新安装对方邻信导致证书变化时，需要先核对新指纹并重新配对；本版尚无图形化重置绑定入口，可在应用关闭后移除文件中对应设备的绑定再连接，不能盲目清理全部信任记录。

局域网和 Tailscale 使用同一个邻信身份，因此不会仅因连接方式变化而产生两个会话。当前仍只保存一个有效连接地址，完整的多路径选择和自动故障切换留待后续。

## 验证范围

本机未安装并登录真实 Tailscale，因此目前完成的是 CLI 模拟与本机独立服务的连接流程测试，以及原生 UI 的设备列表检查。未配置真实虚拟网络，未验证真实跨网吞吐、DERP 路径或 Windows VPN/防火墙行为。

参考：[Tailscale CLI 官方文档](https://tailscale.com/docs/reference/tailscale-cli)。

## 设置弹窗

点击左下角 **设置**，可配置：

- **启用 Tailscale**：控制邻信的 Tailscale 设备入口和状态读取，默认开启。关闭时取消尚未结束的状态查询/连接尝试，并隐藏入口；不退出系统 Tailscale，也不切断已有会话或文件任务。
- **随邻信启动 Tailscale**：启动邻信时打开已安装的 Tailscale 图形客户端，默认关闭。首次保存开启时也尝试立即打开；缺少图形客户端时显示提示，不自动安装、登录或执行 `tailscale up/down`。

点击保存后立即生效，偏好保存在当前数据目录的 `settings.json` 中，重启后保留。取消或 Escape 关闭弹窗不会保存草稿。此处不修改系统开机登录项；“随邻信启动”只随邻信应用启动触发。
